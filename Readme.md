## 📌 About the Project

The **Government Fund Utilization Intelligence Dashboard** is a Power BI project developed to analyze government fund allocation, release, and utilization across financial years, states, and departments.

It provides a consolidated view of sanctioned funds, released funds, utilized funds, and unutilized balances. Interactive visuals help users explore utilization trends, compare yearly performance, and identify departments with higher unutilized fund amounts.

The objective is to make financial data easier to understand through interactive dashboards and data-driven insights.

## 🎯 Project Objectives

- Analyze government funds sanctioned, released, and utilized.
- Monitor fund utilization across financial years.
- Compare fund releases with actual utilization.
- Identify departments with higher unutilized fund amounts.
- Visualize state-wise fund utilization performance.
- Analyze year-over-year changes in fund release and utilization.
- Create an interactive dashboard for financial monitoring.

### 📈 Year-wise Utilization Trend

- **2021–22:** 66.2%
- **2022–23:** 61.0%
- **2023–24:** 64.6%
- **2024–25:** 65.2%

Utilization declined in 2022–23 and improved over the following two financial years, reaching 65.2% in 2024–25.

### 🏢 Department Analysis

The Ministry of Rural Development has the highest unutilized fund amount among the departments shown in the dashboard, at approximately ₹28.1K.

The Ministry of Jal Shakti and Ministry of Education also feature among the departments with higher unutilized fund amounts.

These figures highlight areas for further analysis; unutilized funds alone do not establish the reasons behind the remaining balances.

## 📐 DAX Measures

The dashboard uses DAX measures to calculate key financial indicators, including:

- Total Fund Released
- Total Fund Utilized
- Total Sanctioned Amount
- Unutilized Fund
- Fund Released Rate
- Overall Utilization Percentage
- Previous Year Fund Released
- Year-over-Year Fund Released Change
- Previous Year Fund Utilized
- Year-over-Year Utilization Change

These measures enable dynamic calculations and year-wise comparisons in Power BI.

## 🚀 How to View the Project

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop).
3. Open the Power BI `.pbix` file from the `Dashboard` folder.
4. If necessary, update the source-data path in Power BI.
5. Refresh the data and explore the visuals using the available filters.

You can also explore the dashboard screenshots directly on GitHub.
